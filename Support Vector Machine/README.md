# 📈 Support Vector Regression (SVR)

## 📌 Project Overview

This project demonstrates how to build and deploy a **Support Vector Regression (SVR)** model using Python and Scikit-learn. It covers the complete machine learning workflow from loading the dataset to preprocessing, training the model, tuning hyperparameters using GridSearchCV, evaluating performance, saving the trained model, and deploying it for making predictions.

## 🚀 Features

* Load dataset into a Pandas DataFrame
* Perform One-Hot Encoding for categorical features
* Split data into training and testing sets
* Train a Support Vector Regression (SVR) model
* Optimize model performance using GridSearchCV
* Evaluate model performance using R² Score
* Save the trained model using Pickle
* Deploy the model for making predictions

## 🛠️ Technologies Used

* Pandas
* NumPy
* Scikit-learn
* Pickle
* Jupyter Notebook
